# Multitenant Todo Task

This is a four-member Docker and Jenkins project.

## Team

- Tyron James Beza: project lead and integration
- Rhea Mae Mendoza: frontend and quality assurance
- Kristine Camille Bowman: backend and database
- Samantha Maxene Garcia: infrastructure, worker, and Jenkins

The application allows users to register, log in, and manage private todo lists. Docker runs the application services, MySQL stores the data, the worker creates activity notifications, and Jenkins runs the CI/CD pipeline.

Detailed contribution instructions are in FROM-SCRATCH-GROUP-BUILD-GUIDE.md and MULTITENANT-TODO-TASK-MASTER-GUIDE.md.
